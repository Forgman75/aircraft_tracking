# Aircraft Tracking --- отслеживание самолётов
Консольное Python-приложение для получения информации о самолётах в
воздушном пространстве выбранной страны, просмотра и фильтрации
результатов, а также хранения данных в JSON с импортом и экспортом CSV.

## Возможности
* Получение координат и границ страны через Nominatim
OpenStreetMap.
* Получение данных о воздушных судах через OpenSky Network
API.
* Преобразование ответов API в объекты `Aircraft`.
Сохранение данных в JSON-файл.
* Экспорт данных из JSON в CSV и импорт CSV в JSON.
* Просмотр списка самолётов и поиск по стране.
* Просмотр самолётов с фильтрацией по высоте и скорости.
* Вывод самолётов, отсортированных по высоте.
* Удаление самолётов по позывному.

### Абстрактные базовые классы
- **`APIAdapter`** — общий предок для классов использующих внешнее API (`NominatimAPI`, `OpenSkyAPI`)
- **`BaseStorage`** — общий предок для всех хранилищ данных
(`JSONStorage`, `CSVStorage`)

### Конкретные классы
- **`Aircraft`** - объект самолета с атрибутами (позывной, страна регистрации, высота, скорость) и методами сравнения по скорости и высоте
- **`NominatimAPI`** — класс для работы с API Nominatim OpenStreetMap
- **`OpenSkyAPI`** — класс для работы с API OpenSky Network
- **`JSONStorage`** - класс реализующий хранение данных в JSON-файле
- **`CSVStorage`** — класс для сохранения и чтения самолетов в CSV
